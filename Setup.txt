TestBuddy — Setup & Run Commands
================================

Prerequisites
-------------
- Node.js 20+
- PostgreSQL 18 (local)
  Database : testbuddy
  Username : admin
  Password : admin
  Host     : localhost
  Port     : 5432


1) Create PostgreSQL database (one-time)
---------------------------------------
Open psql as postgres, then run:

  CREATE ROLE admin LOGIN PASSWORD 'admin';
  CREATE DATABASE testbuddy OWNER admin;


2) Backend (Node.js / Express) — port 8080
------------------------------------------
cd backend
npm install
npm run dev

Health check: http://localhost:8080/api/health


3) Frontend (Vite React) — port 5173
------------------------------------
cd frontend
npm install
npm run dev

Open: http://localhost:5173


4) Extension (optional)
-----------------------
cd extension
npm install
npm run pack

Then either:
  - Download zip from http://localhost:5173/  (TestBuddy-extension.zip)
  - Or load unpacked folder: extension\dist

Chrome: chrome://extensions → Developer mode → Load unpacked
Select the unzipped "TestBuddy" folder (contains manifest.json).


5) AI service (optional, hello-world only)
-----------------------------------------
cd ai-service
python -m venv .venv
.\.venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload --port 8001

Health check: http://127.0.0.1:8001/health

Notes
-----
- Start Backend before Frontend / Extension (they call localhost:8080).
- Copy backend/.env.example to backend/.env if needed (defaults match local Postgres).
